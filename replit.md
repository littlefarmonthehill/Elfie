# PlanetBrick - LEGO Business Operations Dashboard

## Overview
PlanetBrick is a business operations and analytics dashboard for LEGO resellers, integrating with BrickLink, BrickOwl, and EasyPost. Its core purpose is to enhance efficiency and profitability through real-time inventory management, order tracking, sales analytics, marketing insights, and an AI chat assistant (E.L.F.I.E.). The platform features a dark-mode, LEGO-inspired user interface.

**Customer Portal (Oct 24, 2025):** The platform features a **Jetsons-style mid-century retro-futuristic landing page** at the root (`/`) with an enlarged PlanetBrick logo at center (w-48 h-48 md:w-72 md:h-72 lg:w-80 lg:h-80) featuring soft radial glows, gentle float animation, and no box border. Four **neon signage navigation plaques** orbit the logo in diagonal positions with atomic-age styling: chrome trim, angled sign posts, starburst accents, neon glow effects, and subtle sway animations. Navigation leads to: (1) **Showroom** (`/showroom`, cyan/blue neon, top-25% right-18%) - Primary CTA with enhanced pulse animation, (2) **Events** (`/events`, amber/orange neon, bottom-35% right-12%) - Upcoming workshops, (3) **Deals** (`/deals`, purple/pink neon, bottom-25% left-18%) - Exclusive bundles, (4) **Community** (`/community`, emerald/green neon, top-25% left-15%) - Videos and news. Each sign displays icon + name + arrow with NO subtitles. Starfield background with atomic age decorative rings. Enhanced gradient tagline at bottom: "Your Universe of LEGO® Parts & Community" (cyan → purple → pink gradient with pulsing glow). Staggered fade-in animations create elegant entrance. The clickable PlanetBrick logo in the showroom banner returns to the landing page. All placeholder pages (Events, Deals, Community) feature cross-page navigation with color-coded buttons and active page highlighting.

## System Architecture

### UI/UX Decisions
The frontend uses React 18+, TypeScript, Vite, Shadcn/ui, and Tailwind CSS, featuring a dark mode with a LEGO-themed color palette and a 3-Tier Responsive Design System. It includes modular dashboards with tab-based navigation, reusable metric cards, drawer-based detail modals, and a dismissible notification system. E.L.F.I.E., the AI Assistant, features an animated mascot and retro-futuristic chat drawer theming, displaying AI-generated text and supplementary data. The UI incorporates layered sticky navigation controls and comprehensive scaling optimization for tablet and desktop views, maintaining a cohesive aesthetic with distinct gradient backgrounds for different sections. A streamlined Settings modal includes cache management and version display.

### Technical Implementations
-   **Frontend:** React 18+, TypeScript, Vite, Wouter, TanStack Query, Shadcn/ui, Tailwind CSS.
-   **Backend:** Express.js with TypeScript and Node.js.
-   **Database:** Drizzle ORM with Neon serverless PostgreSQL, including `pgvector`.
-   **API:** RESTful endpoints.
-   **Authentication:** Email/password system with bcrypt, passport-local, and PostgreSQL session storage. It supports a multi-role system ('customer', 'employee', 'admin') with role-based routing and secure session management, including Zod validation and password change functionality. Authentication pages feature consistent PlanetBrick branding and mobile optimization.
-   **Data Schema:** Comprehensive schema for users, inventory, orders, sync metadata, app settings, embeddings, BrickLink forum posts, warehouse management, picklists, sync issues, and shipping.
-   **Order Status & Inventory Automation:** Centralized configuration for platform-specific order statuses and automated inventory adjustments.
-   **SKU Standardization (Oct 23, 2025):** The `order_details.sku` and `order_details.bricklink_inventory_id` fields are standardized to always contain the BrickLink inventory ID for cross-platform data integrity. **BrickLink orders:** SKU populated from `inventory_id`. **BrickOwl orders:** SKU uses two-tier fallback: (1) `external_lot_ids.other` from API if available, (2) existing SKU if numeric (BrickLink inventory ID format). The `bricklink_inventory_id` column is populated during sync for all items using the same fallback logic. **Automatic Migration:** BrickOwl order sync automatically populates `bricklink_inventory_id` for existing historical orders during regular sync operations, migrating 25,175+ items without manual intervention. All analytics queries updated to join on `sku = CAST(bl_inventory.id AS TEXT)` or use `bricklink_inventory_id` directly.
-   **Shipping System:** Vendor-agnostic abstraction with EasyPost integration for label generation, tracking, and platform status synchronization.
-   **Service Worker & PWA:** Intelligent update system with auto-reload that respects user activity.

### Feature Specifications
-   **Data Flow & System Design:** BrickLink serves as the primary product catalog source. PlanetBrick manages inventory, synchronizes changes to BrickLink and BrickOwl, and adjusts inventory based on orders. A global sync lock prevents race conditions. The system includes a comprehensive sync pipeline for inventory, Rebrickable data, and AI embeddings.
-   **AI Assistant (E.L.F.I.E.) (Enhanced Oct 25, 2025):** Powered by OpenAI (GPT-4o-mini with optimized parameters: temperature 0.5, max_tokens 1600, 8 agent loop iterations), E.L.F.I.E. features **step-by-step reasoning**, **conversation memory synthesis**, and **strategic insight generation**. Advanced function calling with date awareness and tool chaining capabilities. **MULTI-DEPARTMENT ARCHITECTURE (Oct 25, 2025)**: Operates as a multi-department AI organization with cross-departmental collaboration: (1) **Product Department** - Inventory & market intelligence (local inventory, BrickLink catalog, pricing, market trends, category throughput), (2) **Orders Department** - Fulfillment & operations (order analytics, sales history, co-purchase patterns), (3) **Marketing Department** - Customer intelligence & growth (repeat customers, business customers, geographic analysis, demographics), (4) **Sales Department** - Strategic analysis & business intelligence (synthesizing data across all departments for comprehensive recommendations). **Departments collaborate** by using multiple tools together to provide complete answers - e.g., growth strategy questions consult Marketing (customer metrics), Sales (category performance), and Product (market trends) simultaneously. **Balance**: Adapts between strategic multi-department synthesis for business questions vs quick operational data for admin queries. Tools include: BrickLink catalog search, price guides, local inventory search, order analytics, **category throughput** (sell-through rates), **customer loyalty metrics** (repeat customers with usernames), **business customer list** (actual company names), **geographic sales analysis** (state/country with demographic breakdowns), set-part details, web search for market trends, and semantic search of BrickLink forums. **PARTS-FIRST ANALYSIS (Oct 25, 2025)**: System prompt emphasizes **granular part-level analysis FIRST, then category summaries** - start with individual lots/colors/conditions (specific part numbers, exact colors, New vs Used), then broaden to category-level metrics. Targets adult modelers (AFOLs) with technical details, rare piece identification, and MOC building support. Marketing and sales strategy recommendations tailored to the AFOL community. **HISTORICAL DATA CONTEXT (Oct 25, 2025)**: Store was closed for 2 years and is now reopening - all order/sales data is historical (2010-2023, latest order: Dec 28, 2023). Analytics tools default to ALL historical data unless user specifies timeframe. E.L.F.I.E. NEVER assumes recent dates or fabricates order details - only presents actual data from tool results. **Clickable prompts**: Suggestions formatted as `**PROMPT:** "text"` render as interactive buttons with gradient styling, allowing users to click suggestions instead of typing. Integrates image recognition via Brickognize API and uses `localStorage` and a `conversations` table for memory, leveraging RAG with `pgvector` embeddings. Uses markdown formatting for improved readability.
-   **Price-o-Matic:** Bulk pricing intelligence with caching.
-   **Set-Part Relationships:** Integrates Rebrickable data to display LEGO set-part relationships.
-   **Dashboard Layout:** Features a default dashboard with notifications, plus dedicated Inventory, Orders, Sales, and Marketing dashboards with specialized tools.
-   **Customer Shopping Platform (Oct 2025):** Mobile-first **brand showcase and showroom** at `/showroom` featuring **part-number-based product grouping** and **category-based navigation**. The showroom serves as a **brand showcase** with **dual sales approach**: (1) Individual parts link to BrickLink/BrickOwl stores (external "Buy on BrickLink"/"Buy on BrickOwl" buttons), (2) Shopping cart reserved exclusively for curated bundles and experimental offerings not available on marketplaces. Products are grouped by unique part number (itemNo), with all color/condition variations aggregated into a single product. Scoring formula: `(total_value * 0.7) + (log10(total_qty + 1) * 0.3)`. **View Modes (Oct 24, 2025):** Gallery/List toggle with NO horizontal scrolling. Gallery mode displays products in responsive grid (2-5 columns based on screen size, 20 products per section), List mode displays each product as full-width horizontal row with smaller image (w-16 h-16 md:w-20 h-20, ~1/2 gallery size) on left and full product titles with natural wrapping. **Category-Based Navigation:** Interactive category pill selector with multi-select capability allows customers to choose which categories to browse. Active categories move to left of pill bar with cyan-to-blue gradient highlighting and checkmarks, inactive categories alphabetically sorted. Selected categories appear as collapsible sections below special groups. **Special Groupings:** Three permanent sections: (1) New Items - last 30 days, (2) Hot Items - trending based on order velocity, (3) Discounted Items - saleRate > 0. All sections collapsible. **Redesigned Header:** Black background with centered PlanetBrick logo, cart and login buttons in top-right. Stats (Unique Lots/Total Parts) below logo with animated comet trail effects. **Navigation:** Sticky header, sticky search bar, sticky category pill selector. **Product Display:** Gradient band backgrounds per section (emerald/teal/cyan for New, red/orange/yellow for Hot, violet/fuchsia/pink for Discounted, varied gradients for categories). **Product cards use two-line layout (Oct 24, 2025):** Line 1 combines product name with part number ("{LEGO® Product Name} #{partNumber}"), Line 2 displays all badges (color count, emerald "New" badge with total qty, amber "Used" badge with total qty). Cards show first variation's image (sorted: New first by qty desc, then Used by qty desc, then alphabetically). **Detail modal - compact 2-column layout (Oct 24, 2025):** Car sticker aesthetic with gradient border (cyan/blue/purple), bold uppercase header. Left column displays scrollable colors list (one color per row with dot + name). Right column displays two stat cards stacked vertically: Total Parts (New/Used breakdown) and Price Range (min-max per piece). Compact text sizing (text-[10px] md:text-xs for labels, text-xs md:text-base for titles). Prominent BrickLink/BrickOwl buttons at bottom (one set per modal). Clickable color thumbnails open full-screen lightbox with Jetsons orbital glow effects. Color dots use BrickLink RGB values (auto-prefixed with '#'). Jetsons retro-futuristic aesthetic: pure black background with blue/cyan/white gradients. Strategic Shopify alternative with full BrickLink/BrickOwl integration control. **Compliance requirement:** All product and color names display "LEGO®" trademark symbol via runtime utility functions (`formatProductDisplayName`, `formatColorDisplayName` in `client/src/lib/lego-branding.ts`). **Upcoming features:** Curated bundles section (using shopping cart), workshops/events section, community engagement (future: E.L.F.I.E. mini-shows, vlogging).
-   **Notification System:** Dismissible, severity-grouped notification center for sync errors.
-   **Platform Sync:** Multi-platform inventory synchronization system with BrickLink as the source of truth, offering manual sync, real-time progress, and discrepancy detection.
-   **Picklist & Fulfillment:** Bin-level picking system and an order fulfillment system with actions for packing slips, shipping, and order splitting.
-   **Shipped Orders:** Customer support tool for searching and reprinting documents for shipped orders.
-   **Order Sync Tester:** Dry-run tool for validating order sync logic.
-   **Sales Analytics:** Year-over-Year Sales Comparison, Platform Comparison Analysis, and Platform Performance Dashboard.
-   **AI Intelligence & Embeddings Management:** Settings for AI configuration, server-side background jobs for embedding generation (inventory, orders, order details, set-parts using `text-embedding-3-small`), and a semantic search testing interface. Includes analytical tools for inventory aging, margin analysis, SKU performance, and sales by category. Automatic re-embedding triggers are integrated into sync pipelines, processed in batches by a background worker.
-   **Automation & Scheduling:** Centralized controls for automated Inventory Sync, Price-o-Matic, Orders Sync, and BrickLink Forum Sync, with automatic purging of stale forum posts.
-   **Backup & Restore System:** Production-ready disaster recovery with manual and automatic restore options, including Neon PITR, fraud detection, and sync lock integration.
