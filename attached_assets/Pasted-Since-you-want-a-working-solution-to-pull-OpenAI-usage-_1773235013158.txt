Since you want a working solution to pull OpenAI usage for a dashboard, here’s the reliable approach that works with modern project keys (sk-proj-).

The idea is:

1️⃣ Pull usage from the Usage API
2️⃣ Calculate cost locally
3️⃣ Store/display it in your dashboard

This avoids the older billing endpoints that often fail.

⸻

  -H "Authorization: Bearer YOUR_API_KEY"

2. Python Script for Dashboard Monitoring

This script:
	•	fetches usage
	•	calculates cost
	•	shows totals

import requests
import datetime

API_KEY = "YOUR_API_KEY"

headers = {
    "Authorization": f"Bearer {API_KEY}"
}

MODEL_PRICES = {
    "gpt-4.1-mini": {
        "input": 0.00000015,
        "output": 0.0000006
    }
}

def calculate_cost(model, input_tokens, output_tokens):

    if model not in MODEL_PRICES:
        return 0

    price = MODEL_PRICES[model]

    return (
        input_tokens * price["input"] +
        output_tokens * price["output"]
    )


def get_usage():

    today = datetime.date.today()
    start = today - datetime.timedelta(days=1)

    url = f"https://api.openai.com/v1/usage?start_date={start}&end_date={today}"

    r = requests.get(url, headers=headers)
    data = r.json()

    total_cost = 0

    for entry in data["data"]:
        cost = calculate_cost(
            entry["model"],
            entry["input_tokens"],
            entry["output_tokens"]
        )

        total_cost += cost

    return total_cost


cost = get_usage()

print("OpenAI usage (last 24h): $", round(cost, 4))
