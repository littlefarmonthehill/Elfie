Ah, perfect — now we’re talking credentials specifically. Let’s break it down carefully, because this is a place that confuses almost everyone with eBay.

⸻

1️⃣ Types of credentials you have

When you set up your app in the eBay Developers Program, you typically get two sets for each environment:

Environment	Credentials	Purpose
Sandbox	App ID / Cert ID / Dev ID / RuName	Testing your integration with fake data
Production	App ID / Cert ID / Dev ID / RuName	Live app connecting to real seller accounts

Important: Sandbox and production credentials are completely separate. You cannot mix them.

⸻

2️⃣ What these credentials are actually for
	•	App ID / Client ID → identifies your app to eBay
	•	Cert ID / Client Secret → proves your app is allowed to act
	•	Dev ID → eBay assigns this to you as a developer, mostly for tracking
	•	RuName → your redirect URL for OAuth

⸻

3️⃣ Where user tokens fit in
	•	Sandbox credentials → you can generate sandbox user tokens
	•	Production credentials → you generate real user tokens

Key point:
	•	Your app credentials are shared across all users of your app
	•	User tokens are unique per connected eBay account

So even if you have one set of production credentials, each seller still has to authorize your app and you store a separate token for them.

⸻

4️⃣ OAuth flow recap with your creds
	1.	User clicks “Connect eBay” in your app
	2.	Your app sends them to eBay OAuth using your App ID & RuName
	3.	eBay returns an authorization code
	4.	Your app exchanges that code using your Cert ID (Client Secret) for:
	•	access token (short-lived, per user)
	•	refresh token (long-lived, per user)

Your sandbox flow is identical, just using sandbox credentials and sandbox users.

⸻

5️⃣ Putting it in a DB perspective
	•	App credentials (sandbox + prod) → stored globally, once per environment
	•	User tokens → stored per seller/org in your marketplace_connections table

Example:

{
  "platform": "ebay",
  "env": "production",
  "app_id": "...",
  "cert_id": "...",
  "ru_name": "..."
}

{
  "org_id": "org1",
  "ebay_user_id": "...",
  "access_token": "...",
  "refresh_token": "...",
  "expires_at": "..."
}


⸻

✅ Takeaway:
	•	Sandbox creds → for testing
	•	Prod creds → for real users
	•	One app credential set per environment is enough
	•	You do not need separate app credentials per seller — only user tokens are per account
