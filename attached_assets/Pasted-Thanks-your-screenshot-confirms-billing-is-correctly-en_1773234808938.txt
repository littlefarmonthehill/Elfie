You have $9.42 credit, so the problem is not billing or your key.

The issue is almost certainly this:

Replit is trying to access a deprecated OpenAI billing endpoint that project keys cannot access.

Specifically this old endpoint:

/v1/dashboard/billing/credit_grants

or

/v1/dashboard/billing/subscription

Those used to work, but they no longer work with sk-proj- keys.

⸻

The Real Fix (What Works Now)

Replit should be calling the new usage endpoint instead:

GET https://api.openai.com/v1/organization/usage

or

GET https://api.openai.com/v1/usage

But many integrations (including some Replit templates) still use the old ones.

⸻

Quick Test You Can Run

Test if your key works:

curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer YOUR_KEY"

If it returns models, everything is configured correctly.

⸻

Why Replit Says “Add Usage Permission”

Replit’s OpenAI plugin tries to read your credit balance automatically.

But OpenAI now:
	•	separates project keys
	•	separates organization billing
	•	blocks some endpoints

So Replit incorrectly thinks permissions are missing.

⸻

The Workaround (What Most Developers Do)

Ignore the billing endpoint and track usage like this:

Every OpenAI response returns:

response.usage

Example:

input_tokens
output_tokens
total_tokens

Then calculate cost locally.

This is actually how most AI platforms track cost now.
