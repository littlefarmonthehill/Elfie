Now to the actual issue you’re seeing.

Why the billing endpoints are failing

The older endpoints like:

/v1/dashboard/billing/credit_grants
/v1/dashboard/billing/subscription

were part of the legacy OpenAI billing API and many accounts can’t access them anymore, especially when using:
	•	project keys (sk-proj-...)
	•	newer platform billing system

Project keys are scoped to models, not organization billing.

So the API returns errors like:
	•	401 unauthorized
	•	403 access denied
	•	not found

⸻

What works now (recommended)

Instead of the old billing endpoints, use the Usage API.

Example:

curl https://api.openai.com/v1/organization/usage \
  -H "Authorization: Bearer YOUR_API_KEY"

or

curl https://api.openai.com/v1/usage

These return:
	•	tokens used
	•	cost
	•	usage by model
	•	usage by day

⸻

Important difference: Project vs Org keys

Key type	Can access billing	Can call models
Project key (sk-proj)	❌ No	✅ Yes
Org key (legacy sk-...)	✅ Yes	✅ Yes

So if you want billing info programmatically, you may need an organization-level key instead of a project-scoped key.
